# 视觉资源

- `launchpad-wallpaper.png`：内置 Image Gen 生成的 1536 × 1024 背景，用于 `src/App.css`。
- `luma.png`：Launchpad 浅色应用图标的 32px 版本，与 `src-tauri/icons/32x32.png` 保持一致，用于浏览器标签页图标。
- 应用图标由本机系统动态读取，不使用生成的品牌图标，也不随项目分发本机应用列表。

背景生成提示词：

> Full-screen landscape bitmap for a desktop application launcher, 1536 × 1024. Extremely defocused natural landscape. Top 20 percent warm milk-white sky, muted dusty blue distant hills at middle-left, lower two-thirds warm tan, pale ochre and gray-olive rolling hills. Heavy optical blur, soft hazy transitions, low contrast, desaturated calm daylight. Wallpaper only: no application icons, text, logos, UI, dock, borders or watermark. No purple, neon, bokeh circles, sharp edges or foreground objects.
